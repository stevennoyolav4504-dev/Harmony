# Harmony REV.06 品牌素材

PNG 原文件来自用户提供的 `Harmony_VI_Guidelines_CN_Rev06.pptx` 配套资产包，未经重绘或重新着色。原文件的 alpha 通道定义透明区；白色横槽及字标中的白色均属于标志，不得抠除。

- 应用、桌面、任务栏、标题栏：独立图形标置于主背景 `#F9ECF3` 的圆角容器，图形宽度为容器的 72%（手册第 12 页规定 68%–74%）。保持原始长宽比。
- 侧栏窄幅：使用官方文字标，宽 132 个逻辑像素，主背景承载，左右各保留 14 像素，上下各保留 16 像素。
- 帮助页：使用官方标准组合标，主背景承载，保持安全留白。
- 浅色与深色界面均在独立主背景区域显示全彩标志，不直接放在纯白或其他品牌色底上。
- 官方深色及反白原图保留供单色场景使用，不从全彩图自行着色。副背景为 `#EDD43E`，本次默认采用主背景。

运行 `venv\Scripts\python.exe src\tools\build_brand_assets.py` 从上述原图生成 `src/icon.ico` 和 `src/assets/harmony-icon.png`。ICO 包含 16、20、24、32、40、48、64、96、128、256 像素；Windows 运行时继续按 DPI 选取大、小图标。`src/build.bat` 会自动执行此步骤。

完整文字标尚无注册级矢量母版；这些资产按手册用于日常数字应用。
